# Roadmap

## Phase 1 — Self-hosted catalog (current)

- [x] Schema and entry format defined
- [x] Seed entries for core categories
- [ ] 50+ entries across 10+ categories
- [ ] Validation script + CI
- [ ] Contribution workflow documented and tested

## Phase 2 — Static site

- [ ] Auto-generate site from Markdown source (repurpose freestack Astro UI)
- [ ] Search and filter by deploy method, resource tier, auth support
- [ ] Category browsing + comparison views
- [ ] Screenshot/demo link support

## Phase 3 — API vertical

- [ ] Payment APIs (Stripe, Lemon Squeezy, Paddle, etc.)
- [ ] Auth APIs (Auth0, Clerk, Supabase Auth, etc.)
- [ ] Email APIs (Resend, Postmark, SES, etc.)
- [ ] Schema adapted for: pricing model, free tier limits, SDK languages, rate limits

## Phase 4 — Free AI resources

- [ ] Model access (OpenRouter, Groq, Together, etc.)
- [ ] Token/rate limits per provider
- [ ] Commercial use allowed?
- [ ] Comparison by use case (chat, code, embeddings, vision)

## Phase 5 — Free/cheap cloud

- [ ] Always-free tiers (AWS, GCP, Azure, Oracle, Cloudflare)
- [ ] What you actually get vs marketing claims
- [ ] Region availability, gotchas, egress traps
- [ ] Side-by-side comparison tables

## Future

- Community voting / "I run this" endorsements
- Automated freshness checks (last release date, commit activity)
- Integration with deployment tools (one-click compose templates)
- RSS feed for new entries
